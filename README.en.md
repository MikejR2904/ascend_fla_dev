# ascend_fla

Efficient Ascend-NPU implementations of the fla family of linear-attention operators, built on
[ascriptor](https://github.com/ddddwee1/ascriptor) (an instruction-level Python compiler) and exposed
as torch-callable ops. The goal is to be faster than what exists today.

This is not a fork of fla, nor a backend plugin for it — the public API is defined here, and `fla`
serves only as the semantic authority during testing (`naive.py` as a CPU fp32 oracle). See `AGENTS.md`.

# A2-07 Qwen3-Next 上 A2 的 GDN ABI 方案（调研 + 设计，不写 kernel）

- 波次 / SoC：W0 / a2（纯主机侧，桌面调研 + `ascriptor check` / sim 取证）
- 优先级：P1 · 时限：12h · 依赖：A2-01
- 需要：ascriptor workspace、fla（对照 GDN 语义）
- 写集：`docs/research/a2_gdn_abi.md`

## 目标

首波的第二个模型是 Qwen3-Next-80B-A3B，走 GDN。它被六项 ABI 缺口挡着，而且全是 kernel 改动。本任务要产出一份
能直接拆成 kernel 批次（A2-K1 的 GDN 部分）、交给用户审批的设计文档。

## 背景（摘录）

Qwen3-Next 的形状见 `docs/matrix/models.json`：hidden 2048、key heads 16、value heads 32、head_k = head_v = 128、conv 4。

上游 `a5/gdn_fwd` 五阶段对着 fla 是这么映的：preprocess（g_cumsum / decay_mask）↔ `gated_delta_rule/gate.py` 加 cumsum；
inverse（严格下三角求逆）↔ `ops/utils/solve_tril.py`；recompute ↔ `wy_fast.py`；scores ↔ `chunk_o.py`；
recurrent ↔ `chunk_delta_h.py`。`gdn_bwd` 含全部反向保存值。

六项缺口在 `gaps.json` 里：`gdn-no-gqa`（domain 只有 B,H,C，没有独立的 value-head 维）、`layout-not-token-major`
（公开布局是 `[B,H,C,L,D]`）、`nonzero-initial-state`、`d-initial-state-absent`（反向不出 dh0）、`state-dtype-bf16`、
`fused-recurrent-missing`（GDN decode kernel 整族缺失）。另外还牵着 `scale-param-no-slot` 和 `no-tail-path`。

KDA 在这六项上都已经具备（`AGENTS.md` §2 的对照表），所以 KDA 的实现就是现成的参照：GQA 用 `HV % H == 0`、
token-major 公开布局在内部 permute、FP32 state 进出、反向出 dh0、decode kernel 一核一头不需要核间同步
（`a5/kda_fused_recurrent`）。

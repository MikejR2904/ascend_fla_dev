# A2-07 Qwen3-Next 上 A2 的 GDN ABI 方案（调研 + 设计，不写 kernel）

- 波次 / SoC：W0 / a2（纯主机侧，桌面调研 + `ascriptor check` / sim 取证）
- 优先级：P1 · 时限：12h · 依赖：A2-01
- 需要：ascriptor workspace、fla（对照 GDN 语义）
- 写集：`docs/research/a2_gdn_abi.md`

## 目标

首波第二个模型是 **Qwen3-Next-80B-A3B**（GDN）。它被六项 ABI 缺口挡着，全是 kernel 改动。本任务产出一份可以直接
拆成 kernel 批次（A2-K1 的 GDN 部分）交给用户审批的设计文档。

## 背景（摘录）

- Qwen3-Next 形状（`docs/matrix/models.json`）：hidden 2048、key heads 16、value heads 32、head_k = head_v = 128、conv 4。
- 上游 `a5/gdn_fwd` 五阶段对 fla：preprocess（g_cumsum / decay_mask）↔ `gated_delta_rule/gate.py` + cumsum；
  inverse（严格下三角求逆）↔ `ops/utils/solve_tril.py`；recompute ↔ `wy_fast.py`；scores ↔ `chunk_o.py`；
  recurrent ↔ `chunk_delta_h.py`。`gdn_bwd` 含全部反向保存值。
- 六项缺口（`gaps.json`）：`gdn-no-gqa`（domain 只有 B,H,C，无独立 value-head 维）、`layout-not-token-major`
  （公开布局 `[B,H,C,L,D]`）、`nonzero-initial-state`、`d-initial-state-absent`（反向不出 dh0）、`state-dtype-bf16`、
  `fused-recurrent-missing`（GDN decode kernel 整族缺失）。另有 `scale-param-no-slot`、`no-tail-path` 相关。
- KDA 在这六项上都已具备（`AGENTS.md` §2 对照表）—— **KDA 的实现是现成的参照**：GQA 用 `HV % H == 0`、token-major 公开布局内部 permute、
  FP32 state 输入输出、反向出 dh0、decode kernel 一核一头无需核间同步（`a5/kda_fused_recurrent`）。

## 交付文档须含

1. 逐缺口：现状（引用上游 kernel 源码行）→ 改法设计（参照 KDA 对应实现）→ 影响的 kernel 列表 → 契约变更 → 数值风险（量程、dtype）→ 验证计划（fp32 双 oracle：fla naive 与 chunk↔recurrent 互验）→ 工作量估计。
2. A2-01 命中表中 GDN 各 kernel 的 split-K 暴露及对设计的影响。
3. 按 `AGENTS.md` §6「量程」一节：GDN 链上所有 `exp` / 除法 / cumsum 类算式逐处列表判量程（真实初始化下的门控跨度要单独估，不要照搬 KDA 的 94）。
4. Qwen3-Next 其余层（gated full attention、MoE、RMSNorm 等）在 910B 上需要的 torch_npu 算子清单 —— 真机覆盖要到 A2-10 才能测，这里只列清单与"缺了会怎样"。
5. 建议的 kernel 批次拆分（每批的内容、依赖、预计验收），供 PM 交用户审批。

## 这条任务是怎么来的

A2-44（PR #99）让公开 `chunk_kda` / `fused_recurrent_kda` 支持 fla 式 raw flags，但 q/k 的 l2norm、`g = −exp(A_log)·softplus(g+dt_bias)`、beta 的 sigmoid 仍在 host 侧用 PyTorch 算子（FP32）完成（`chunk._prepare_inputs`，chunk 与 decode 共用），再舍入 / 传给 kernel。
`ascend_fla/layers/kda.py` 也走这条路（`use_qk_l2norm_in_kernel=True, use_gate_in_kernel=True`）。D-PM-35 / D-PM-37：BF16 计算与 dtype 转换必须在自编译 kernel 里；这三步是 D-PM-40 / D-PM-42 登记的「raw flags 存量例外」，本任务把它们搬进 kernel 并消除该例外。

## 范围：`_prepare_inputs` 的三步（当前语义，逐条以源码为准）

| 步骤 | 触发 | 输入（当前接受） | 计算（FP32） | 输出 |
|---|---|---|---|---|
| gate | `use_gate_in_kernel` | `g[B,T,HV,128]`、`A_log[HV]`、`dt_bias[HV*128]`，任意 floating | `g_out = −exp(A_log)[h] · softplus(g + dt_bias[h*128+k])`（`torch` 默认 softplus，beta=1、threshold=20） | FP32 `g_out[B,T,HV,128]` |
| q/k l2norm | `use_qk_l2norm_in_kernel` | `q,k[B,T,H,128]`，任意 floating | `x / sqrt(Σ_k x² + 1e-6)`（加性 epsilon，FLA v0.5.2） | 舍入到 `qk_dtype`：chunk 为 BF16，decode 为 `v.dtype`（BF16 或 FP32） |
| beta | `use_beta_sigmoid_in_kernel` | `beta[B,T,HV]`，任意 floating | `sigmoid(beta)` | FP32 `beta_out` |

- 某个 flag 关闭时对应输入**原样透传**（不进 kernel、不拷贝）——`_prepare_inputs` 现有的「never changes a disabled route」要保持，FP32 / 不带 flag 的路径改前改后逐位相同。
- **dtype 域（PM 裁定，D-PM-40 同型）**：raw `q/k/g/beta`（及 `A_log` / `dt_bias`）只接 **BF16 或 FP32**，kernel 内加宽 / 计算；FP16 / FP64 / 其它显式报错并说清哪条约束不满足（这是从「任意 floating（靠 host 加宽）」收窄——合入前 PM 单列给用户，你不要自行放宽或收得更窄）。输出 dtype 见上表；decode 的 `qk_dtype=v.dtype` 边界保持。
- **不做**：不改 `check_domain` 启发式与门控跨度检查的语义（它们是只读校验，D-PM-42 单列，BF-07 后仍是登记的只读例外）；不碰 `_scan_states` / `dw` 取负 / `log2(eg)`（FMT-02 登记的另一批存量例外，不属本任务）。

## 阶段 1：前向 / 推理 / decode（必做）

- 新单元 `kda_prep`：gate、q/k l2norm、beta sigmoid 三个（或按实现合并的）自编译 kernel；公共入口在 `chunk_kda` / `chunk_kda_fwd*`（不需要梯度：`no_grad` 或所有输入都不 `requires_grad`）与 `fused_recurrent_kda`（decode，只推理）里调用它们，host 只做分配 / 元数据 / 只读校验 / launch。
- **q/k 的 K=128 行内求和**：求和顺序会影响舍入，要在实现前固定（例如按 64 lane 分块再固定顺序合并），写进文档，且与 `bd` 无关（`bd` 间逐位相同）。
- 需要梯度且 raw flag 开着时：阶段 1 允许**暂时**保留现有 host `_prepare_inputs` 图（登记的存量例外，审计单列、给源码行），由阶段 2 消除；不得因此改变梯度语义。

## 阶段 2：梯度链（必做，或经 PM 拆成 BF-08）

- 一个新的 `torch.autograd.Function`（或扩展 `_ChunkKDA`）包住前处理：前向调阶段 1 的 kernel，反向由**自编译 backward kernel** 产出 raw `q/k/g/beta` 与 `A_log` / `dt_bias` 的梯度，输入是 `chunk_kda_bwd` 给出的对「已处理的」q/k（BF16）、g（FP32）、beta（FP32）的梯度。公式（自行推导并在文档里逐项验证，下面只是提示）：
  - l2norm：`y = x·r`，`r = (Σx²+ε)^(−1/2)`；`∂L/∂x = r·gy − r³·x·(x·gy)`（行内点积，K=128）。
  - gate：`u = g + dt_bias`，`g_out = −exp(A_log)·softplus(u)`；`∂L/∂g = ∂L/∂g_out · (−exp(A_log)·sigmoid(u))`；`∂L/∂A_log[h] = Σ_{b,t,k} ∂L/∂g_out · g_out`；`∂L/∂dt_bias[h·128+k] = Σ_{b,t} ∂L/∂g_out · (−exp(A_log)·sigmoid(u))`。
  - beta：`∂L/∂beta = ∂L/∂beta_out · s·(1−s)`。
- **`A_log` / `dt_bias` 的梯度要对 (B, T) 归约**——跨核归约必须**确定性且与 `bd` 无关**（固定分块 + 固定顺序的两级归约，工作区写在 GM 里），`bd` 间逐位相同仍是硬判据；不用原子加。
- 阶段 2 完成后 host 侧不再有前处理的算术 / 转换算子（前向与反向都过审计）；raw 输入部分 / 全部 `requires_grad` 的组合、「只有 `A_log` / `dt_bias` 要梯度」都要覆盖。

## 预算与判据（实现前冻结，事后不得放宽）

**PM 不预设数字，你先校准**：把校准（对 FP64 参考的误差地板 F、逐量的分布）与由它导出的预算作为**第一个提交**（BF-02 的 `1a3cf5a` 那种做法），再写 kernel。PM 评审时核对：预算不比校准地板的 3 倍更松、没有空洞比较（零预算除外）、每个预算实现前后没变。下面是必须定的量：

- **前处理输出**对 FP64 参考与对 host `_prepare_inputs`（用一份逐字节钉住的前任副本，方式同 FMT-02 的 `baseline/`）：`g_out` / `beta_out`（FP32，逐元素相对误差与相对 L2）、q/k（BF16 或 FP32 输出，RNE 舍入位置差异：逐元素不超过 1 ulp、相对 L2 ≤ min(1e-2, 3F)、超 1 ulp 的元素数为 0 或有解释）。**不要求与 host 逐位相同**（`exp` / `log1p` / `sigmoid` / `sqrt` 的实现不同，舍入位置不同），但要**量化写明差**。
- **端到端**：`chunk_kda` 的 `o` / `final_state` 与六个梯度（对两个 CPU FP32 参考，预算沿用现有：`o` / state 0.05，dq / dv / dbeta / dh0 0.05、dk 0.15、dg 0.25，不放宽）；对 host-prep 路径同一输入的差报出来。
- **`bd` 间逐位相同**（含阶段 2 的归约），FP32 / 无 flag 路径改前改后逐位相同，输入不被修改，输出 NaN 预填后完整写满。
- **门控闸不变**（前向 155 / 反向 105）：融合后在跨度 {0, 100.8（fla 默认初始化的上界）, 105, 155} 上量化前后差，闸值不改（要改先问用户）；「有限」与「准」分别报。
- **按「量程」列表逐处判**（`AGENTS.md` §6）：`exp(A_log)` 上溢、softplus 的 threshold=20 两侧与大负值下溢、sigmoid 饱和、`x²` 上溢 / 下溢（`|x|` 很大 / 很小）、`eps=1e-6` 与零 / 近零行——每一处写成表，说明是「下溢到 0 就是对的」还是要闸，闸要双边实测；行为与 host 路径对不上的（NaN / Inf 传播等）要写明。

## 已知陷阱

- 三个前处理之间共享 `_prepare_inputs` 的**校验**（`raw_tensor` 的连续性 / 浮点检查、`A_log` / `dt_bias` 形状）——校验留在 host（只读），别连校验一起搬走；连续性检查失败要报错，**不要悄悄 `contiguous()`**。
- decode 与 chunk 共用同一个 helper：改动前后 BF-06 已合入的 decode 行为（含 `qk_dtype=v.dtype`、bd 支持集、raw flags 边界 84 条）逐位不变。
- 前处理的 `A_log` / `dt_bias` 梯度是**全局归约**，最容易做成与 `bd` 相关的顺序——一开始就按固定分块设计。
- fla 默认初始化的 gate 跨度约 94、上界 100.8，反向闸 105；融合不许把闸的可用域悄悄缩窄（缩窄是域变化，先问用户）。

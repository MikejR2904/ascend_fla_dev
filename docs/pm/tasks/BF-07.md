## 这条任务是怎么来的

A2-44（PR #99）让公开 `chunk_kda` / `fused_recurrent_kda` 显式支持 fla 式 raw flags，但 q/k 的 l2norm、`g = −exp(A_log)·softplus(g+dt_bias)`、beta 的 sigmoid 仍在 host 侧用 PyTorch 算子（FP32）完成，再 cast 成 BF16 喂 kernel
（`gaps.json` 的 `qk-l2norm-not-in-kernel` 只收窄、没有标融合完成）。按用户的「BF16 计算必须 kernel 侧」，这三步应当进 kernel。这条与 `A2-42`（a2、gated）范围相同，但目标是 A5。

## 范围骨架

- BF16 的 raw `q/k` 进 kernel，kernel 内 FP32 做 `x/sqrt(Σx²+1e-6)`（加性 epsilon，FLA v0.5.2）后作 cube 的 BF16 operand；门控与 beta sigmoid 同理在 kernel 里。host 侧不再有这三步的算术与 cast。
- 数值对 A2-44 的 host 实现：不要求逐位相同（舍入位置不同），要量化写明差；门控跨度的闸（前向 155 / 反向 105）要在融合后**重测双边**，改锚点不改数学但改舍入。
- 精度、真机、host 算子审计口径同 `docs/pm/bf16-kernel-side.md`。

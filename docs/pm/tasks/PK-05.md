## 范围骨架（PM 在 GDA-03 完成后按其经验补全，下面只是已知的硬约束）

- **域与前向 `PK-03` 逐项一致**，不悄悄扩大：`initial_state` / `initial_A_state` 只接受 None（因此没有 `dh0`、`dA0` 输出）、
  T 是 64 的倍数且 ≤ 4096、`HV%H==0`、`block_dim∈{1,2}`、归一化必须开启。
- **上游梯度有三路**：`do`、`dht`（主 state）、`dA_T`（ATK 的 final_A_state）。三路的各种组合都要覆盖。
- **要求导的东西比 GDN 多**：q/k 的 `F.normalize`（含 `1e-12` 钳位与近零行）、ATK 递推 `A_t = exp(g_atk)·A_{t-1} + beta_atk·k²`
  的反向、有界 squash 的 `M`、**读/写 key 不对称**（`k_read` 与 `k_write` 两条路径对 `k` 的梯度都要计入）；
  `g_atk`、`beta_atk` 是 per-`H` 的，来自组内所有 value head 的梯度要**汇总**，不能复制。
- **预研事实（申领人在 #89 下的 CPU 预研，自述，PM 未独立核实；交付物里仍须自己重做）**：独立 CPU 反向递推对 pin 版 PGDN naive 的自动微分，
  七个输入梯度、三路 cotangent（输出、主 state、ATK state），六个 case（分组比 1/2/4/8、一/两个 chunk、零/极小 q/k、`beta_atk=0`），
  最大相对 L2 **1.0479961e-6**。关键细节：**组内 value-head 的贡献先归约，再进共享的 per-`H` ATK 伴随；final ATK cotangent 每个 `H` 只播种一次**。
- **oracle**：A = 对 pin 住的 `precond_gated_delta_rule` naive 做 CPU FP32 自动微分；B = 独立解析反向；两者先过 FP64 gradcheck。
  **PGDN 的 naive 做归一化、PKDA 的不做**（`pkda_semantics.md` §7），别把两个算子的结论互相套用。
- **内部 kernel 形参名避开 C++ 关键字**：GDA-03 的第一次真机构建栽在形参名 `do`（生成的 aclnn 头文件/cpp 里是 C++ 保留字），改内部形参名 `dout`、公共 ABI 不变才过（申领人自述）。本任务同样有 `do`，别再撞一次。
- **预算与口径同 GDA-03**：FP32 每个梯度相对 L2 ≤ 1e-4，先校准再实现，事后不得放宽；BF16 只作质量检查；逐梯度报数字。
- **真机与同卡测量同 GDA-03**（完整 workload 先跑、`bd=1/2` 逐位相同、三轮三明治如实标注基线、不设速度门槛）。
- 机器与卡归 assignee 自己管理（D-PM-28）。

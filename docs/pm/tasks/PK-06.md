## 范围骨架

- 在 `GDA-04` 的基础上加 **ATK 状态**：主 state `[B,HV,128,128]` 与 ATK 对角状态 `[B,H,128]` 是**两个独立的递推量**，
  都要带非零初始值输入、更新后输出；两者的形状与所有权（ATK 按 `H`、不随 `HV` 复制）不能混。
- **归一化语义必须与 `PK-03` 一致**（PGDN 的 naive 做 `F.normalize`，`eps=1e-12`）；读/写 key 不对称（`k_read` / `k_write`）保持。
  **PM 已对 pin 住的源码核实（2026-09-19）**：fla 的 `precond_gated_delta_rule/fused_recurrent.py:130-132` 用**加性 epsilon** 归一化
  `x / sqrt(Σx² + 1e-6)`（公共函数 `use_qk_l2norm_in_kernel` 默认 True，`fused_recurrent.py:362`），**与 naive 的 `F.normalize` 分叉**。
  decode 若照 fla 的 fused_recurrent，prefill→decode 的 state 在近零行上就不连续；所以 **decode 必须显式保持已接受的 naive 归一化**，
  并量化写明这处分叉；不得静默采用 fla 的 fused_recurrent 语义（要采用需用户另行决定）。
- **prefill→decode 一致性**：`PK-03` 的 `final_state` 与 `final_A_state` 都要能接着递推。
- 精度、oracle、测量口径同 `GDA-04`；BF16 同样显式拒绝、不 host 加宽（用户 D-PM-35）；机器与卡归 assignee 自己管理（D-PM-28）。

## 范围骨架

- **先 profile，不要先信推断**（`AGENTS.md` §6 铁律一）：GDN 前向（GDA-01/02）、GDN 反向（GDA-03）、PGDN 前向/反向
  （PK-03/PK-05）、两个 decode（GDA-04/PK-06）各自的设备侧耗时与 host 开销拆开，缓存键必须是 O(1)。已知一个事实：PK-03 的
  T=4096 前向约 566 ms，其中 ATK 是逐 token 串行；先量出各阶段占比，别凭这一个数字下结论。
- **目标要可测量、要在 profile 之后由 PM 定**；每次只改一件事，每件事一个小 PR；精度预算不变（FP32 ≤ 1e-4 判定），不放宽换速度。
- **测量**：同卡同步三明治，原始样本保留，基线如实标注身份；`bd` 间逐位相同的硬判据保持。
- 机器与卡归 assignee 自己管理（D-PM-28）。
